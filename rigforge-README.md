# RIGFORGE V40 — On-Device APK Forge

**Build a signed, installable APK 100% on the phone. No servers, no external build chain.**

RIGFORGE is a single HTML file of 13 MB and about 48,805 lines that forges an Android APK entirely on the device itself.

## What it does

- Its own compiler (RIG Compiler, in C, sovereign) — no external build dependencies
- APK Signing Block v2 signing with a persistent key
- 3D phone preview, RigArt materials and screens, WebView
- Live Cards (Cartas Vivas): widget and APK icon designer with the local AI RIGADIEL built in — it generates the icon from a text instruction and applies it to the APK

## Tested live

RIGADIEL generated a "Phoenix" icon as a 192 x 192 PNG from an instruction in Spanish, and it was applied as the APK icon.
